# Frontend guidance and asset attribution

- Better Interface by Jakub Krehel, MIT, pinned commit `267330e1adfc66a718fb65fa6918c1f06d0a689e`. Applied the supplied local guide across accessibility, layout, writing, typography, colors and UI. [Upstream](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e/skills/better-interface).
- Impeccable documentation method by Paul Bakaus, Apache-2.0, pinned commit `9d715cc4f5564a990ca8345abfdd5df6dc9b41c8`. The implemented-design documentation follows the locally supplied adaptation. [Upstream document](https://github.com/pbakaus/impeccable/blob/9d715cc4f5564a990ca8345abfdd5df6dc9b41c8/skill/reference/document.md). These are distinct works with their original licenses, retained together in [the supplied license text](licenses/Better-Interface-and-Impeccable.txt).
- Austin Griffith's ethskills frontend UX guide, MIT, pinned commit `06ea4efa08076ff04f6ca4945ef4a2ca881115b0`. Applied its assignment adapter for wallet state, transaction progress, errors, units and metadata. The upstream website was not fetched. [License and provenance note](licenses/eth-frontend-ux.txt).
- The supplied IdentityMD wallet connector reference informed EIP-6963, mobile app-browser links and Coinbase Smart Wallet integration. Current [Wagmi configuration](https://wagmi.sh/react/api/createConfig) and [Coinbase connector documentation](https://wagmi.sh/react/api/connectors/coinbaseWallet) were consulted for API compatibility.
- MetaMask, Rabby and Phantom marks are the original SVG assets distributed by `@rainbow-me/rainbowkit` 2.2.11; Coinbase's mark follows the supplied connector reference. [RainbowKit license](licenses/RainbowKit.txt). No RainbowKit runtime or dependency archive is shipped. Wallet names and marks identify their respective products.
- Rabby's current app-browser link uses its source-defined `_cmd=open-dapp&dapp=…` handler. [Handler source](https://github.com/RabbyHub/rabby-mobile/blob/develop/apps/mobile/src/hooks/universalLink.ts). Native app behavior remains a device-level validation limitation.
- The generic Uniswap interfaces and error names follow the supplied swap specification, [Uniswap swap documentation](https://developers.uniswap.org/docs/protocols/v4/guides/swapping/swapping), [QuoterRevert](https://github.com/Uniswap/v4-periphery/blob/main/src/libraries/QuoterRevert.sol) and [BaseV4Quoter](https://github.com/Uniswap/v4-periphery/blob/main/src/base/BaseV4Quoter.sol). No address was taken from those external sources. Live reads confirmed that the empty active tick range could still quote in one direction, consistent with the [pool's tick-crossing implementation](https://github.com/Uniswap/v4-core/blob/main/src/libraries/Pool.sol).
- Packet artwork, favicon, share-card composition and UI outline icons were drawn in local SVG/HTML code for this frontend. They use no remote image or font service.

Third-party npm dependencies retain their own license metadata in the lockfile and packages. The guide licenses above are notices for the guidance used, not a relicensing of the repository or wallet trademarks.
